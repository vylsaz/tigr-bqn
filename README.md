# tigr-bqn
A [tigr](https://github.com/erkkah/tigr) binding for BQN.

## Usage

### Import

```bqn
tigr ← ⟨ parentFolderOfDLL ⟩ •Import "tigr.bqn"
```
If no argument is supplied, use the default search path.

### Bitmaps

```bqn
# namespace (constants)
tigr.flag
```
Flags for window creation. Add together to use multiple flags.

```bqn
bmp ← title flag tigr._WindowWithFlag size
bmp ← title tigr.Window size
```
Creates a new empty window with a given bitmap size.
- size: `⟨width, height⟩`
- flag: see `tigr.flag`

Returns a bitmap object.

`tigr.Window` is equal to `0 tigr._WindowWithFlag`.

```bqn
bmp ← tigr.Bitmap size
```
Creates an empty off-screen bitmap.

```bqn
tigr.Free bmp
```
Deletes a window/bitmap.

```bqn
tigr.With bmp‿Func
```
Calls `Func` with window/bitmap until user closes the window or presses ESC.
Then frees the window.

```bqn
bmp.W @
bmp.H @
bmp.Size @
```
Get the size (unscaled) of the bitmap object. `Size@` is `⟨W@, H@⟩`.

```bqn
pix ← (x‿y) bmp.ReadPix n
(x‿y) bmp.WritePix ⟨⟨r, g, b, a⟩, ...⟩
```
Access the `pix` of bitmap object directly. If `x‿y` is omitted, use `⟨0, 0⟩`.

```bqn
isClosed ← bmp.Closed @
```
Returns `1` if the user requested to close a window, `0` if not.

```bqn
bmp.Update @
```
Displays a window's contents on-screen and updates input.

```bqn
isAvailable ← bmp.BeginOpenGL @
```
Called before doing direct OpenGL calls and before `Update`.

Returns `1` if OpenGL is available, `0` if not.

```bqn
bmp.SetPostShader shader
```
Sets post shader for a window.

This replaces the built-in post-FX shader.

```bqn
bmp.SetPostFX ⟨p1, p2, p3, p4⟩
```
Sets post-FX properties for a window.

The built-in post-FX shader uses the following parameters:
- p1: hblur - use bilinear filtering along the x-axis (pixels)
- p2: vblur - use bilinear filtering along the y-axis (pixels)
- p3: scanlines - CRT scanlines effect (0-1)
- p4: contrast - contrast boost (1 = no change, 2 = 2X contrast, etc)

### Drawing

```bqn
pixel ← bmp.Get ⟨x, y⟩
```
Helper for reading pixels.
For high performance, just use `bmp.ReadPix` directly.
- pixel: `⟨r, g, b, a⟩` (when a pixel is accepted as an input, you can omit `a` and use the default (`255`))

```bqn
pixel bmp.Plot ⟨x, y⟩
```
Plots a pixel.
Clips and blends.
For high performance, just use `bmp.WritePix` directly.

```bqn
bmp.Clear color
```
Clears a bitmap to a color.
No blending, no clipping.
- color: same as `pixel`.

```bqn
color bmp.Fill ⟨x, y, w, h⟩
```
Fills a rectangular area.
No blending, no clipping.

```bqn
color bmp.Line ⟨x0, y0, x1, y1⟩
```
Draws a line.
Start pixel is drawn, end pixel is not.
Clips and blends.

```bqn
color bmp.Rect ⟨x, y, w, h⟩
```
Draws an empty rectangle.
Drawing a 1x1 rectangle yields the same result as calling `bmp.Plot`.
Clips and blends.

```bqn
color bmp.FillRect ⟨x, y, w, h⟩
```
Fills a rectangle.
Fills the inside of the specified rectangular area.
Calling `bmp.Rect` followed by `bmp.FillRect` using the same arguments causes no overdrawing.
Clips and blends.

```bqn
color bmp.Circle ⟨x, y, r⟩
```
Draws a circle.
Drawing a zero radius circle yields the same result as calling `bqn.Plot`.
Drawing a circle with radius one draws a circle three pixels wide.
Clips and blends.

```bqn
color bmp.FillCircle ⟨x, y, r⟩
```
Fills a circle.
Fills the inside of the specified circle.
Calling `bmp.Circle` followed by `bmp.FillCircle` using the same arguments causes no overdrawing.
Filling a circle with zero radius has no effect.
Clips and blends.

```bqn
bmp.Clip ⟨cx, cy, cw, ch⟩
```
Sets clip rect.
Set to `⟨0, 0, -1, -1⟩` to reset clipping to full bitmap.

```bqn
bmp.BlitKeepAlpha @
bmp.BlitBlendAlpha @
```
Set blend mode for blit operations.

```bqn
⟨dest_x, dest_y⟩ dest tigr._Blit_      src(‿size)        ⟨src_x, src_y⟩
⟨dest_x, dest_y⟩ dest tigr._BlitAlpha_ src(‿size)‿alpha ⟨src_x, src_y⟩
⟨dest_x, dest_y⟩ dest tigr._BlitTint_  src(‿size)‿tint  ⟨src_x, src_y⟩
```
Blit functions. See [tigr.h](https://github.com/erkkah/tigr/blob/v3.2.2/tigr.h#L160) for full document.
- dest, src: bitmap objects.
- size: if omitted, use `src.Size @`.

### Font Printing

```bqn
# namespace (constants)
tigr.codepage
```
Codepages:

- ascii: Regular 7-bit ASCII
- cp_1252: Windows 1252
- utf32: Unicode subset

For ASCII and 1252, the font bitmap should contain all characters
for the given codepage, excluding the first 32 control codes.

For UTF32 - the font bitmap contains a subset of Unicode characters
and must be in the format generated by tigrFont for UTF32.

```bqn
font ← codepoint tigr.LoadFont bmp
font ← tigr.tfont # built-in font
```
Loads a font from a bitmap font sheet.
- codepoint: see `tigr.codepage`

```bqn
tigr.FreeFont font
```
Frees a font and associated font sheet.

```bqn
color dest font._Print_ text ⟨x, y⟩
```
Prints UTF-8 text onto a bitmap.
NOTE:
 This uses the target bitmap blit mode.
 See tigrBlitTint for details.
- dest: bitmap object

```bqn
font.TextWidth  text
font.TextHeight text
font.TextSize   text
```
Returns the size of a string.

### User Input

```bqn
⟨mouse_x, mouse_y, buttons⟩ ← bmp.Mouse @
⟨left, middle, right⟩ ← 3↑32‿1•bit._cast ⋈buttons
```
Returns mouse input for a window.

```bqn
⟨delta_x, delta_y⟩ ← bmp.ScrollWheel @
```
Reads the delta of the scroll "wheel" in somewhat platform neutral
units where 1.0 corresponds to a "notch". The actual correlation between
physical movement and this number varies between platforms, input methods
and settings.

```bqn
# namespace (constants)
tigr.key
```
Key scancodes. For letters/numbers, use ASCII (`'A'`-`'Z'` and `'0'`-`'9'`).

```bqn
isDown ← bmp.KeyDown key
isHeld ← bmp.KeyHeld key
```
Reads the keyboard for a window.
Returns `1` if a key is pressed/held, `0` if not.

`KeyDown` tests for the initial press, `KeyHeld` repeats each frame.
- key: see `tigr.key`

```bqn
char ← bmp.ReadChar @
```
Reads character input for a window.

### Bitmap I/O

```bqn
bmp ← tigr.LoadImage pngFileName
bmp ← tigr.LoadImageMem pngData
```
Loads a PNG, from either a file or memory.

```bqn
ok ← bmp.SaveImage fileName
```
Saves a PNG to a file.
On error, returns zero and sets errno.

### Helpers

```bqn
deltaTime ← tigr.Time @
```
Returns the amount of time elapsed since tigrTime was last called, or zero on the first call.

```bqn
(bmp) tigr.Error message
bmp.Error message
```
Displays an error message and quits.

```bqn
color ← tigr.Hex hexColor
```
Converts [css-style hex-color](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/hex-color) to color.
